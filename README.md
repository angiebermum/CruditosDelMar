# Cruditos del Mar

Aplicación web de catálogo y pedidos para Cruditos del Mar.

## Tecnologías utilizadas actualmente

- React.js
- JavaScript
- Vite como herramienta de desarrollo y compilación

Firebase está previsto para etapas posteriores y todavía no está implementado.

## Requisitos

- Node.js
- npm

## Instalar dependencias

```bash
npm install
```

## Ejecutar localmente

```bash
npm run dev
```

## Compilar

```bash
npm run build
```
